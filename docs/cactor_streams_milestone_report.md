#### **3. 简化流处理API**
```cangjie
// 流处理链式操作
let result = StreamFactory.fromArray([1,2,3,4,5])
    .map({ x => x * 2 })
    .filter({ x => x > 5 })
    .to(StreamFactory.foreach({ x => println(x) }))
    .run()
```
