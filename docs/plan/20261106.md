# CActor 全面审计与整改计划（2026-11-06）

> 基于四路并行静态审计（runtime/typed 核心、cluster/remote/persistence、foundation/patterns/streams、
> 测试与文档），全部结论经 Read/Grep 实证并抽查复核，行号对应 2026-11-06 磁盘工作区内容。
> 此前性能计划见 [perf20261101.md](perf20261101.md)（已实施完毕），本计划聚焦正确性、假实现与工程卫生。

## 0. 总体结论

性能与内存目标已达成（1M Actor 1182B/Actor、typed 路径 30M+、5M 规模与 soak 通过），
但库的**可信度**存在系统性问题：公开 API 中存在成片的"简化实现"假货
（JSON 反序列化、Timer 平均值、快照保存、Backoff 监督、SmallestMailbox 路由、时间戳），
分布式层零鉴权，持久化层静默丢数据。这些假实现比功能缺失更危险——用户以为有，实际没有。

问题统计：**P0 × 4，P1 × 9，P2 × 13，P3 × 9**，共 35 项（详见 §1）。

| 严重级 | 含义 | 数量 | 主题 |
|---|---|---|---|
| P0 | 公开 API 直接产出错误结果 | 4 | 序列化/监控/持久化假实现 |
| P1 | 正确性缺陷或承诺未兑现 | 9 | 监督/路由/流/远程/持久化 |
| P2 | 一致性、安全加固、重复实现 | 13 | 集群一致性、CI 门禁、死代码 |
| P3 | 死代码、文档过时、整洁 | 9 | 死代码清理、ROADMAP/CHANGELOG |
